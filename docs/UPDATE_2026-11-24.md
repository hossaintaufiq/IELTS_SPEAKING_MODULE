# Update, 2026-11-24

Where the IELTS speaking service stands at the end of today, and what we do tomorrow. Tomorrow's focus: **test it more, and start integrating with ieltsup.**

## Done today

### 1. First live GPU test (RTX 3090)
- Rented the cheapest 3090 on vast.ai (about $0.24/h), set the service up with the project's own scripts, and ran it for the first time on a real GPU. Cost about $0.40 in total. Instance destroyed afterwards.
- One full test works end to end through the new `/v1/session` API with an API key.
- Capacity ramp (simulated candidates, no limit on sessions):
  - up to **9 at once**: as fast as a single test (comfortable limit)
  - up to about **26**: no errors, replies about 2 s slower
  - **29**: very slow (GPU memory 23.6 of 24 GB)
  - **32 and above**: the examiner stops answering about half of the answers
- Problems found: GPU memory is not freed after an overload (stayed at 23 GB with no tests, needed a restart), and past the limit the examiner goes silent instead of refusing new tests.
- Full report and raw numbers: `docs/GPU_TEST_2026-11-24.md`, `docs/gpu_test_2026-11-24/`.

### 2. Monitor and test page
- Test page (`/`) is clean: no log links or options, just the test.
- Monitor (`/monitor`) is one page with a navbar: Overview, Run log, Tests, Failures, Server log. Full width, paged lists, a reply-delay chart per test, a conversation-style run log, one server log. `/logs` redirects to it.

### 3. Repo and contract
- Repo root is the service, experiments live under `experiments/`, and local `main`, company `main` and `origin/main` are identical (`935668b`). Merged branches deleted.
- The ieltsup team answered the first contract questions (PR #42): the browser connects **directly** to our service behind a token-style gate, we send a **webhook** first and they fetch the result after a timeout if it was missed, we choose the retention, and no extra events are needed.
- We sent them 16 follow-up questions (token, allowed websites, webhook address and signing, retries, domain and TLS, rejoin, one test per booking, staging, privacy, contact). **Answers are still pending.**
